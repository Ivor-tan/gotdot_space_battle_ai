# 舰船、掉落与构筑

具名玩家可选飞船的数值、武器特色、专属升级路线与羁绊引用见 [玩家可选飞船设计](player_ship_designs.md)。

## 舰船角色与获得方式

| 角色 | 职责 | 示例能力 |
| --- | --- | --- |
| 指挥舰 | 可交换的指挥/量子职责 | 主炮、范围协同、舰队锚点联动 |
| 突击舰 | 前排破阵 | 撞击、破盾、近战弹幕 |
| 守卫舰 | 前排保护 | 护盾、近距火力、相邻支援 |
| 炮击舰 | 后排输出 | 光束、散射、追踪导弹 |
| 控制舰 | 聚怪与减速 | 电磁瘫痪、引力场、量子标记 |
| 支援舰 | 护盾与增益 | 护盾、收集范围、能量补给 |
| 无人机母舰 | 持续功能输出 | 无人机、炮塔、近距无人机 |

- 普通怪掉落星核微粒（经验）。
- 精英怪掉落大型经验核心，并小概率掉落角色信标；该信标使下一次升级至少出现一张对应角色的随机舰船招募选项。
- Boss 必掉舰船信标：高稀有舰或指定角色招募。
- 获得同名舰船时，该舰同样作为一艘“待部署舰”进入舰船编辑；玩家可将它部署到空格，或拖到一艘**同名且同星**的已部署舰上执行融合。两艘舰融合为一艘高 1 星的舰，双方占用的格位只保留目标舰原格位。
- 1 / 2 / 3 星分别需要融合两艘同名同星舰升至 2 / 3 / 4 星；4 星为单局上限。升星优先强化该舰武器特色与固有被动，具体系数见 `player_ship_designs.md`。

## 升级与构筑

每次经验升级提供 3 选 1。

| 选项池 | 目标占比 | 作用 |
| --- | ---: | --- |
| 单舰强化 | 45% | 保留既有卡牌，强化指定舰的主炮、副炮、护盾、引擎或无人机。 |
| 舰队协议 | 30% | 作用于全队、角色或相邻链路，如前排护盾、全队射速、同标签共鸣。 |
| 随机舰船 | 25% | 从当前可用舰船池随机生成招募选项；同名舰也可获得，供玩家在编辑页补位或融合升星。 |

- 前 3 次升级至少出现一次单舰强化和一次舰队协议。
- 第 4、8、12、16、20 级至少出现一项随机舰船招募选项。
- 每次升级的三个选项独立随机抽取，可同时出现舰船与单舰强化、舰队协议等其他增益；保底规则只保证类别出现，不预设固定三选一组合。
- 保留 2 次免费重掷、1 次封牌；连续 5 次未出现史诗以上时，第 6 次至少出现一项史诗或传说。

### 选择结算与应用

升级选择按结果分流，避免普通增益额外打断战斗，也避免新舰绕过格位与羁绊预览：

1. 选择单舰强化、舰队协议、角色/标签增益时，在升级弹窗内完成必要的目标选择，并立即应用效果；弹窗关闭后恢复战斗。
2. 选择会新增一艘舰船的随机舰船招募、具名信标或遭遇奖励时，先锁定该舰为“待部署舰”，随后自动进入**舰船编辑页面**。待部署舰尚未计入舰队、格位收益或羁绊。
3. 在舰船编辑页面选择合法空格，可同时调整既有舰船。确认后才部署待部署舰，并在同一帧重算格位、链路、标签协同与羁绊；随后恢复战斗。
4. 将待部署舰拖到合法空格，即部署为独立舰；拖到同名、同星且未达 4 星的已部署舰上，则高亮“融合升星”。确认融合后原子移除待部署舰与目标舰，以目标舰的格位和本局实例 ID 生成高 1 星舰；目标舰已有的单舰改造、护盾与临时状态按“升星继承规则”重算，不会复制两份效果。
5. 取消舰船编辑不会消耗该次舰船奖励，返回其来源选择页；重新确认或改选其他候选后才结算。满编时仍允许获得重复舰进入编辑页与现有同名舰融合；若没有可融合目标，才提供替换或 15 `RUN_EXP` 转化。4 星同名舰不能再融合，重复奖励直接转为 15 `RUN_EXP`，不进入编辑页。

舰船编辑期间战斗保持暂停，与升级选择相同；它是奖励结算页，不消耗额外资源。

## 卡牌作用范围

| 标识 | 说明 | 示例 |
| --- | --- | --- |
| `指挥舰` | 任意合法格位的指挥舰 | 主炮穿透、量子协同、锚点联动 |
| `指定舰` | 玩家选择符合条件的一艘 | 为炮击舰加散射镜、为守卫舰强化护盾 |
| `角色` | 同角色全体 | 所有无人机母舰无人机数 +1 |
| `邻接` | 本舰与六邻格 | 相邻热能舰共享燃烧层数 |
| `羁绊` | 指定具名舰船与所需站位 | 日冕与潮汐相邻时触发日冕引爆 |
| `舰队` | 全阵列 | 全舰队经验收集范围 +25% |

单舰最多装备 3 个核心武器改造与 2 个生存改造，允许王牌舰成型，但要求队友提供保护和供能。

## 击毁、补员与风险

舰船未被护盾抵挡地命中一次即被击毁，立即离开阵列并释放原格位；舰队最后一艘舰船被击毁时本局失败。支援舰、补给和卡牌只能提供护盾、控制或位移，不能复活被击毁舰船。后续升级、信标或遭遇奖励获得的新舰船可部署到任意合法空格，优先用于补员；危机波由当前波数方案的阶段 3 末波与后期加压波触发，并优先冲击当前薄弱环位。
