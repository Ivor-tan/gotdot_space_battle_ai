# 单局流程与 MVP

## 单局流程

```text
选择初始舰与初始护卫 → 清理怪群并收集经验 → 升级：随机舰船招募 / 单舰强化 / 舰队协议等增益
→ 招募新舰、填补空格、编辑前中后排并激活羁绊 → 精英波：获得角色信标，形成首条协同
→ 危机波：使用阵型重构、护盾与控制维持链路 → Boss：获得高价值信标，扩编或培养王牌舰
→ 终局 Boss：检验完整舰队 Build → 结算：解锁新舰蓝图、卡牌与下局起始选项
```

| 波次阶段 | 目标舰队规模 | 体验目标 |
| --- | ---: | --- |
| 阶段 1（第一段设计波次） | 3～5 艘 | 学会移动、首张指定舰强化与基础站位；波末选择第一条路线。 |
| 阶段 2（第二段设计波次） | 6～9 艘 | 建立角色分工，完成精英波；波末选择第二条路线。 |
| 阶段 3（第三段设计波次） | 10～15 艘 | 展开第二环，完成危机波；波末选择第三条路线。 |
| 阶段 4（剩余设计波次） | 16～19 艘 | Build 成型，完成守关波；最后一波后直接挑战终局 Boss。 |

## MVP 实现顺序

1. 实现中心 + 第一环共 7 格、可交换的虚拟舰队锚点，以及指挥、炮击、守卫、支援四种角色。
2. 升级池按单舰强化 45%、舰队协议 30%、随机舰船招募 25% 验证选择吸引力；每次升级的三项候选独立随机，允许舰船与其他增益同屏。
3. 为既有主炮、副炮、护盾、引擎、无人机卡添加作用范围，不重做全部数值。
4. 实现舰队编辑：安全窗口、45 秒阵型重构、合法性校验与预览。
5. 实现 4 条二舰羁绊，优先验证日冕引爆与生命壁垒。
6. 实现 5 / 8 / 10 / 15 / 20 / 30 波预设、自定义 4～60 波、无限循环、三个路线断点与波数 HUD，再接入普通怪经验、精英角色信标、Boss 高稀有信标三层掉落。

## 待验证问题

- 19 艘舰船是否降低可读性；优先通过轮廓、角色图标与编队缩放解决。
- 王牌舰投入与扩编收益是否平衡；各预设与自定义波数在各自第二个路线断点都应可行，无限模式前三循环不能只由单一 Build 支配。
- 舰船被击毁后释放格位、后续随机招募能否提供足够的补员与翻盘空间。
- 信标频率能否让玩家感到舰队成长，同时不挤占常规强化选择。
- 阵型重构的 45 秒冷却、3 艘移动上限与减速代价是否能形成救场选择，而不是固定循环操作。
- 羁绊提示是否能让玩家在 19 艘规模下快速判断可激活组合；若不能，应优先压缩为图标、连线与缺失成员提示。
