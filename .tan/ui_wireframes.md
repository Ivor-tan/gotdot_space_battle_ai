# UI 线框设计

> 低保真布局说明。`[按钮]` 表示可操作项，`<信息>` 表示动态信息，`+-----+` 表示容器边界。所有战斗内页面默认支持键盘/手柄焦点与鼠标操作。

## 页面导航

```text
主页
├─ 开始航行 → 起始舰队选择 → 游戏页
├─ 蓝图库 / 飞船档案
├─ 图鉴 → 飞船图鉴 / 敌方图鉴 / 羁绊图鉴
├─ 设置 → 音频 / 画面 / 操作 / 无障碍
└─ 退出游戏

游戏页
├─ 升级选择（自动弹出）
├─ 舰船信标 / 招募选择（自动弹出）
├─ 舰队编辑（安全窗口或阵型重构）
├─ 暂停菜单
│  ├─ 舰队状态
│  ├─ 设置
│  └─ 返回主页（确认弹窗）
└─ 结算页 → 下一局 / 返回主页
```

## 主页

```text
+--------------------------------------------------------------+
|                       星 海 奇 点                            |
|                  <当前解锁：12 艘飞船>                       |
|                                                              |
|                    [ 开始航行 ]                              |

|                    [ 设置 ]                                  |
|                    [ 退出游戏 ]                              |
|                                                              |
| 左下：<版本号>                         右下：[按键提示]       |

```

- 默认焦点为“开始航行”。
- 背景仅展示缓慢移动的舰队剪影，不放置影响可读性的实时战斗信息。

## 起始舰队选择

```text
+--------------------------------------------------------------+
| [返回]                  选择本局初始舰                       |
|                                                              |
| +----------------+  +----------------+  +----------------+  |
| | 奇点           |  | <未解锁初始舰> |  | <未解锁初始舰> |  |
| | 量子 / 指挥    |  | 解锁条件       |  | 解锁条件       |  |
| | 主炮与固有被动说明 |  |                |  |                |  |
| +----------------+  +----------------+  +----------------+  |
|                                                              |
| 初始编队：仅 1 艘，部署于中心格                              |
| 起始加成：<所选舰船特性与局外已解锁路线预览>                 |
| 难度：     [轻松 / 标准 / 困难]                              |
| 波数预设：[5 快速] [8 短局] [10 标准] [15 扩展] [20 长局] [30 远征] |
```

- 选择卡显示舰种、标签、武器特色、固有被动与可形成羁绊；确认前可选择难度与波数预设、自定义 4～60 波或无限循环。切换无限模式时隐藏自定义波数输入，并显示“每 10 波循环 Boss、Boss 后可安全撤离”的说明。
- 未解锁项显示条件，不允许进入详情后再报错。

## 游戏页（局内 HUD）

```text
+--------------------------------------------------------------+
| <阶段 2 · 波次 03 / 10>  <路线选择：波 4 后>  [暂停 Esc]   |
|                                                              |
| <已部署舰船：3>  <可补员空格：2>  <护盾层：3>  <等级 7 经验 ████░> |
|                                                              |
|                                                              |
|                  ┌────── 战斗区域 ──────┐                   |
|                  │  敌人、投射物、蜂巢舰队 │                   |
|                  │  危险预警与 Boss 标记   │                   |
|                  └─────────────────────┘                   |
|                                                              |
|                                                              |
|                                                              |
+--------------------------------------------------------------+
```

- HUD 常驻信息只保留阶段、当前波次 / 总波数、下一次路线选择波次、生存、成长、波次危险和暂停入口。
- 无限模式显示为“循环 2 · 波次 03 / ∞”与“路线选择：循环内波 4 后”；循环 Boss 后显示安全撤离入口，普通波次不显示撤离入口。
- 羁绊只显示图标与数量；悬停/焦点才展开名称、成员和剩余失效时间。
- Boss 出现时顶部替换波次信息为 Boss 名称、阶段与生命条。

## 升级选择弹窗

```text
+--------------------------------------------------------------+
|                         升级：选择 1 项                      |
|                                                              |
| +----------------+  +----------------+  +----------------+  |
| | 单舰强化       |  | 舰队协议       |  | 随机舰船招募   |  |
| | 日冕：伤害+20% |  | 前排伤害+12%   |  | 随机稀有控制舰 |
| | <作用范围>     |  | <作用范围>     |  | <可能角色>     |  |
| +----------------+  +----------------+  +----------------+  |
|                                                              |
| [重掷 2] [封牌 1]                    <下一次保底提示>        |
+--------------------------------------------------------------+
```

- 暂停战斗，仅此类选择页面可暂停。
- 每张卡必须显示作用范围：指定舰、角色、邻接、羁绊、舰队锚点或舰队。
- 选择单舰强化、舰队协议或角色/标签增益时，在此弹窗内完成目标选择并立即应用；关闭弹窗即恢复战斗，不跳转舰队编辑。
- 选择会新增舰船的卡时，先展示舰船缩略图、推荐格位、可形成羁绊及可融合目标，然后自动进入“舰船编辑（待部署）”；新舰确认部署或融合前不生效。无合法空格但存在同名同星舰时，仍生成该卡以允许融合。

## 舰船信标与招募选择

```text
+--------------------------------------------------------------+
| [关闭]                    舰船信标                           |
|                                                              |
| +----------------+  +----------------+  +----------------+  |
| | 潮汐           |  | 磁暴           |  | 舰船奖励        |  |
| | 引力 / 控制    |  | 电磁 / 控制    |  | 为已拥有舰升星  |  |
| | 中排推荐       |  | 中排推荐       |  | <目标舰选择>    |  |
| | 羁绊：日冕引爆 |  | 羁绊：蜂群回路 |  |                 |  |
| +----------------+  +----------------+  +----------------+  |
|                                                              |
| <选择后填入一个合法空格；击毁后释放的格位可直接补员> [确认招募] |
+--------------------------------------------------------------+
```

- 已拥有羁绊成员时，用连线和“缺少成员”提示突出可完成组合。
- 满编时若存在同名同星目标，仍显示“获得待部署舰 → 编辑页融合”；不可融合时才替换为“替换 / 转化经验”二选项，不隐藏代价与失去的舰船。

## 舰队编辑

```text
+--------------------------------------------------------------+
| [取消]  舰船编辑 <待部署：潮汐 1★>               [确认变更]  |
|                                                              |
|                    ○ 后排格    ○ 后排格                      |
|              ○ 中排格     ○ 中排格     ○ 中排格              |
|                    [舰] -- [舰] -- [舰]                      |
|              ○ 前排格     ○ 前排格     ○ 前排格              |
|                                                              |
| 左侧：待部署舰 / 可移动舰船  右侧：部署、融合与变更预览      |
| +---------------+        +--------------------------------+ |
| | 壁垒  前排    |        | 护盾层：+1 → +0                | |
| | 芽舱  中排    |        | 射程：+10% → +10%              | |
| | 日冕  后排    |        | 羁绊：日冕引爆 [激活]          | |
| +---------------+        | 羁绊：生命壁垒 [将断开]         | |
|                            +--------------------------------+ |
+--------------------------------------------------------------+
```

- 舰船奖励进入本页时战斗暂停，不消耗重构次数、冷却或移动数量；取消返回奖励来源，待部署舰不消失。
- 将待部署舰拖到空格为部署；拖到同名同星、低于 4 星的舰船卡为融合。融合预览显示“2 艘 <舰名> <星级> → 1 艘 <舰名> <星级+1>”、保留格位、属性变化及将清除的护盾/临时状态；不合法目标明确显示原因。
- 可放置格高亮；不可放置格显示原因：未解锁环、断开连续性或已被其他舰船占用。舰船被击毁后原格立即显示为可补员空格。
- 确认部署前预览待部署舰带来的格位收益、标签链路、羁绊变化与被替换代价；确认后一次性部署并恢复战斗。
- 绿色标记新增增益，红色标记失去增益；连线区分标签链路与羁绊链路。
- 主动开启的舰队编辑仅在安全窗口或暂停菜单中开放，取消不消耗任何资源。

## 暂停菜单与子菜单

```text
+----------------暂停----------------+
| [继续游戏]                           |
| [舰队状态]                           |
| [设置]                               |
| [返回主页]                           |
+-------------------------------------+
```

```text
+----------------舰队状态----------------+
| [返回]  舰队  羁绊  本局构筑           |
|                                        |
| 舰队：<舰船列表、护盾、格位、已部署状态> |
| 羁绊：<激活 / 缺少成员 / 已失效原因>    |
| 构筑：<已选卡牌与作用范围>              |
+---------------------------------------+
```

```text
+------------------设置------------------+
| [音频] [画面] [操作] [无障碍]           |
| 音频：主音量 <────●──>                  |
| 画面：屏幕震动 [开/关]                  |
| 无障碍：色弱标记 [开/关]  字号 [标准]   |
|                         [返回]          |
+----------------------------------------+
```

- 返回主页必须二次确认，正文明确提示“本局进度将丢失”。
- 舰队状态为只读；实际换位必须进入舰队编辑，避免暂停菜单绕过战斗限制。

## 蓝图库与图鉴

```text
+--------------------------------------------------------------+
| [返回]    [飞船] [敌方] [羁绊] [卡牌]       <搜索 / 筛选>    |
|                                                              |
| +----------+ +----------+ +----------+ +----------+         |
| | 日冕     | | 潮汐     | | 壁垒     | | ???      |         |
| | 已解锁   | | 已解锁   | | 已解锁   | | 未发现   |         |
| +----------+ +----------+ +----------+ +----------+         |
|                                                              |
| 详情：角色 / 标签 / 推荐格位 / 解锁方式 / 羁绊关联           |
+--------------------------------------------------------------+
```

- 未解锁内容只显示轮廓、名称占位和解锁条件；不会提前泄露完整数值。
- 敌方图鉴在首次遭遇后记录行为和反制提示，强化学习而非只作收藏。

## 结算页

```text
+--------------------------------------------------------------+
|                         本局结算                             |
| <胜利 / 失败>       <存活时间 18:26>       <最高波次 9>      |
|                                                              |
| 本局舰队：<舰船数>  最高羁绊：<名称>  击败精英：<数量>       |
| 解锁： [飞船蓝图] [卡牌] [起始选项]                          |
|                                                              |
| [ 再来一局 ]                           [ 返回主页 ]           |
+--------------------------------------------------------------+
```

- 失败时给出最近 10 秒内最主要的舰船击毁/伤害来源，帮助理解失败原因。
- 解锁卡点击可进入对应图鉴详情；再来一局保留上次初始舰选择但不保留局内构筑。

## 关键状态反馈

| 状态 | HUD 表现 | 详细页表现 |
| --- | --- | --- |
| 舰船被击毁 | 舰队摘要减少数量并显示可补员空格，战场留下短暂残骸特效。 | 显示击毁来源、已释放格位与下一次招募可补员提示。 |
| 羁绊激活 | 图标点亮。 | 显示成员、站位条件和效果。 |
| 羁绊被干扰 | 图标闪烁并显示倒计时。 | 显示干扰来源与恢复条件。 |
| 危机波 | 顶部警示类型与倒计时。 | 暂停菜单显示反制建议。 |
| Boss 阶段转换 | 顶部阶段条与短提示。 | 图鉴记录新阶段机制。 |
