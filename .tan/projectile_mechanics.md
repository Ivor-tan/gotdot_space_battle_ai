# 投射物与舰船机制闭环

本文为 `player_ship_designs.md` 中的牵引、燃烧、无人机、电弧、扇形炮及其专属升级提供统一的运行时契约。数值上限、护盾与控制时长统一服从 `combat_rules.md`；本文不引入生命回复、永久属性或手动施放按钮。

## 1. 通用实体与事件

每个命中只产生一次 `HitEvent`：`sourceShipId`、`sourceInstanceId`、`projectileId`、`targetEnemyId`、`damage`、`position`、`tags`。同一投射物对同一目标的重复接触必须去重；穿透、弹射或范围伤害都要生成新的、可追踪的命中事件。

效果结算顺序固定为：

1. 命中判定与基础伤害。
2. 伤害修正（易伤、专属节点、星级、卡牌），再执行单发伤害上限。
3. 命中附带状态（燃烧、牵引、减速、标记、过载）。
4. 由状态或命中触发的二次效果（爆炸、弹射、反击）。
5. 清理失效投射物、到期状态和超额实体。

所有状态以 `sourceInstanceId + effectId + targetId` 为键；同来源同效果刷新持续时间或提高层数，不建立无限实例。控制类状态同类取较长剩余时间，仍不超过 3 秒硬上限。

## 2. 弹体通用规则

| 类型 | 命中模型 | 生命周期 | 上限与异常处理 |
| --- | --- | --- | --- |
| 直射弹 | 首个有效碰撞目标；穿透时按路径顺序继续 | 命中、射程耗尽、离屏或最大寿命后回收 | 同一目标单发只命中一次；穿透目标数不超过 8 |
| 爆炸弹 | 落点或命中点半径查询 | 命中后立即结算一次范围伤害 | 爆炸半径不超过 180；同次爆炸每目标一次 |
| 导弹 | 锁定目标，失锁后直飞到最大寿命 | 命中、目标失效后超时或离屏 | 不重新锁定不可见/已回收目标；最多一个锁定目标 |
| 电弧 | 从首目标按最近有效目标跳转 | 跳转结束立即回收 | 最多 6 跳；同一链内不重复目标；每跳按衰减系数结算 |
| 扇形炮 | 以发射方向与角度扇区筛选 | 单帧完成判定或生成短寿命弹片 | 每轮只对同目标结算一次；角度、射程受战斗上限限制 |
| 无人机攻击 | 无人机是短生命周期实体，发射独立投射物 | 返航、超时、载机失效或达到数量上限后回收 | 单舰无人机数与全局投射物上限同时生效 |

投射物池复用时必须清空命中集合、锁定目标、链路索引、状态标签、计时器、可见性和信号订阅。所有节点/物理 API 仅在主线程访问。

## 3. 状态机制

### 牵引与重力井

- 牵引只改变敌人的期望移动向量，不传送、不穿墙、不改变敌人基础移速配置。
- 每次牵引写入方向、强度、结束时间；同类效果取较大强度并刷新较长时间。
- 强度以“向效果中心的速度修正百分比”结算，普通敌人最多 55%，精英/Boss 先乘控制抗性。
- 重力井为地面持续效果：每 0.5 秒对范围内目标施加一次牵引，不叠加多个计时器；同来源区域重叠时刷新范围区，不重复创建。
- 目标死亡、离开地图或效果中心失效时立即移除状态。牵引不会造成伤害，除非具体节点明确产生控制伤害。

### 燃烧与日斑

- 燃烧保存层数、每层伤害、下次跳伤时间和到期时间；每秒结算一次。
- 同来源燃烧最多 3 层；新命中先刷新持续时间，再在上限内增加层数。不同来源不额外增加层数，只取较高每层伤害。
- 跳伤使用原命中来源，触发击杀归属、经验和“燃烧目标”条件；跳伤不触发普通命中型爆炸，除非节点显式写明。
- 日斑是 0.6 秒延迟后的一次性范围效果；同一落点半径内的日斑合并为一次，保留较高伤害，防止高射速重复铺设。
- “燃烧三层爆裂”消耗三层并在同目标 5 秒冷却内最多触发一次；爆裂为独立范围命中，不给原目标重复结算两次。

### 减速、麻痹与过载

- 减速按乘法合并，单目标最终移速不低于基础值的 35%；同类减速刷新较长持续时间。
- 麻痹使行动效率降为 0，持续时间受 3 秒控制上限限制；Boss 先应用控制抗性。
- 过载记录电弧命中计数；同一来源在 3 次有效电弧后激活 3 秒。过载爆裂只能由下一次非电弧伤害消耗，并有每目标冷却。
- 所有控制效果在敌人对象池回收时清空，避免下一次生成残留状态。

## 4. 舰船专属武器闭环

### 潮汐：牵引弹

牵引弹命中后施加一次短牵引；`GRV` 路线提高强度、增加减速并在同区域累计三次后生成重力井。`WAV` 路线在牵引结束时结算控制伤害，并按第五次牵引生成有限目标的回卷。`RLY` 路线只对已受控制目标提供易伤，跨舰触发必须记录不同 `ShipId`，最多三艘。

### 日冕：爆炸、燃烧与日斑

爆炸弹以命中点为中心结算。`FUR` 路线赋予燃烧、溅射和三层爆裂；`FLR` 路线生成日斑并限定延迟与合并；`SIE` 路线只在超远距离命中时生效，连续三次命中同一区域后把下一次爆炸标为强化爆炸。强化爆炸计数在目标区域过期、舰船失效或本次触发后归零。

### 蜂群航母：无人机

无人机状态机为 `Launch -> Acquire -> Attack -> Return -> Despawn`。载机只维护自己的无人机列表；目标失效时从 `Acquire` 重新选取，不跨舰共享。`SWM` 路线控制无人机数量、连击与临时无人机；`HNT` 路线为首命中标记并给标记目标的无人机伤害修正；`GRD` 路线改变近身目标优先级与近身反击。载机被击毁时，所有归属无人机立即停止攻击并回收。

### 风暴链路：电弧

电弧选取首目标后，在未命中集合中按距离、威胁和“正在攻击相邻舰”优先级选择下一跳。每跳伤害按固定衰减，不低于原伤害的 35%。`CHN` 路线增加跳数、命中后施加攻击间隔惩罚并在连续四个不同目标后施加麻痹；`OVR` 路线维护过载并定义非电弧引爆；`NET` 路线改变首选目标、投射单位减速与周期性电网。电网按来源合并且每目标每次只结算一次。

### 铁幕守卫：扇形炮

扇形炮以舰船朝向、扇形角度和射程筛选目标，按距离由近到远结算。扇区内同一目标每轮一次命中；扇形角度扩大不得超过设计硬上限。`FRN` 路线仅在前侧格位启用；`CNT` 路线在失盾后将“下一轮扇形炮”标记为反击，并由命中数决定护盾；`COV` 路线为扇区内敌人减速、精英命中减速，并在连续命中后强化下一轮角度/射程。反击和强化均有独立冷却，舰船换位或失效时清空。

## 5. 局外节点到局内选择

局外解锁仅使节点可进入候选池。局内候选必须同时满足：目标 `ShipId` 在场、玩家等级达到节点层级要求、同舰前层已在本局选择，且该舰尚未选择其他分支。选择成功后写入该舰 `runUpgradeId` 集合；同 `ShipId` 的新招募舰继承集合，其他舰不继承。结算、放弃或重新开始时清空所有 `runUpgradeId`。

每个节点 UI 必须显示：局外解锁状态、局内等级条件、目标舰是否在场、同分支前层状态、互斥分支原因、完整效果、冷却与上限。没有合法目标的节点不得占用升级卡位。

## 6. 验收与调试事件

- 每种投射物记录 `Spawn / Hit / Expire` 三类节流调试事件；不在每帧输出。
- 牵引、燃烧、电弧、无人机和扇形炮各有独立可复现场景：普通敌人、精英、Boss、对象池复用和上限压力测试。
- 验证同一投射物不会对同目标双重命中；状态到期/对象池回收后不残留；控制与投射物上限不被专属节点突破。
- 验证三分支互斥、同舰继承、跨舰不继承、结算清空，以及局外购买但未在本局选择时不产生战斗效果。
